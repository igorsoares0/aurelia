Aurelia — theme handoff

Section & block map · settings · accessibility contract · September 2026

This document is what turns the design files into an Online Store 2.0 theme. It lists every template, the sections each one is built from, the blocks inside those sections, and the settings each exposes to the merchant. Where a decision is still open, it says so rather than inventing an answer.

Design files

Storefront — home, collection, product, PDP variant states, mobile. Commerce & Content — cart page and drawer, search, journal, accounts, utility pages, gift card, password. Explorations — the three original home directions and the type-pair comparison, kept for reference.

4 · Accessibility contract

These are not preferences. Each one is implemented in the design files and each one is checkable in review.

  1. Contrast: body and label text meets 4.5:1 on both the off-white and the dark scheme. The accent is #7A5E30 on light, #C9A96A on dark. A merchant colour override must be validated, not trusted.
  2. Focus: every interactive element shows a visible ring. Custom radio pickers hide the input, so the ring is drawn on the visible label child — losing that rule silently fails the primary buy control.
  3. Touch targets: 44px minimum on every control, including the quantity steppers and the disclosure summary.
  4. Variant availability is never communicated by colour alone: unavailable combinations are dashed and explained in text; sale is worded as well as coloured.
  5. Forms: real labels, error text tied by aria-describedby, aria-invalid on the failing control, and a role="alert" summary. Never a placeholder as the only label.
  6. Live regions: filter counts, quantity changes, predictive-search counts and add-to-bag results are announced politely.
  7. Landmarks and headings: one h1 per template, no skipped levels, every nav carries an accessible name, skip link first in the tab order.
  8. Motion: scroll reveal is opacity and small translation only, and is fully disabled under prefers-reduced-motion.
  9. Zoom and reflow: layouts hold at 200% zoom and 320px width — hence the rem scale and the minmax(0,1fr) grid tracks.

5 · Still open

  1. Font handles. The mocks load Playfair Display and Work Sans from a font CDN because that is what the design tool can render. The theme must use font_picker, and the chosen defaults must be verified against the live library.
  2. Preset styles. Two more presets are expected on a premium listing. The two alternate type pairs and the two alternate home directions in Explorations are the intended source.
  3. Metafields. Piece number, maker name, gram weight, material provenance and care history are all designed but not yet defined as metafield definitions.
  4. Not yet designed. Order detail, addresses, register/reset/activate, stockists, and any localisation-specific layout (currency selector, RTL).
  5. Performance budget. No framework, no jQuery, section JS deferred, images through image_url with width descriptors. Lighthouse has to clear the store threshold on a real device, not a laptop.
